# 第 3 期｜32B 教师与 8B 学生硬件探测及时间预估

[主入口](./experimental_setting.md) · 使用[第 1 期环境](./phase1_model_prep.md)和[第 2 期](./phase2_data_prep.md)预留的 16 人 pilot 区块。本期交付硬件证据和三条路线的工时表。正式排序、校准、训练与效果检验分别在后续阶段执行。

## 1. 实验目标

在同一张 H100 80GB 上分别回答三个问题。原版 8B 能否完成窗口推理，32B-AWQ 能否生成可交给 8B 的角色示范，以及 8B 能否分别完成一次全参数 SFT 或 LoRA-SFT 的真实参数更新。教师和学生分时加载，二者通过离线示范连接。C 固定 128 人、T 固定 256 人，硬件探测仅使用 pilot 样本。耗时估计用于安排单卡作业，正式样本规模固定。

## 2. 实验内容

### 硬件探测

| 路径 | 最小实测 | 证据 |
|---|---|---|
| 原版 8B 主线 | 从 pilot 取典型长度与接近输入上限的四岗窗口，以主线设置分别计时四角色、单综合评审 | revision、后端、精度、批大小、输入/输出 token、加载秒数、有效窗口/小时与峰值显存 |
| 32B 教师 → 8B 学生 | 用 AWQ 教师生成四种角色的短示范并保存，卸载教师后由 8B tokenizer 和训练数据管道读取相同的角色提示、排序和附加概率头 | AWQ 内核可用性、教师吞吐与峰值显存、显存释放、示范到学生 batch 的端到端记录 |
| 8B 全参数 SFT | 取上述示范做前向、反向和完整优化器更新，记录可训练参数数、优化器状态分配后的峰值和步时 | 精度、优化器、梯度累积、有效 batch、显存及训练 token/s。更新后切回推理模式测学生重评吞吐，OOM 时记录失败操作与配置 |
| 8B LoRA-SFT | 从同一基础 8B 单独初始化共享适配器（rank 16、alpha 32），用相同样本完成一次更新，再加载更新后的适配器做推理 | 可训练参数数、适配器梯度与更新、训练吞吐、学生重评吞吐及峰值显存 |

全参数和 LoRA 两种训练探测各用独立的临时状态。记录梯度检查点、CPU offload、量化等实际选项。启用 offload 的结果单列配置与墙钟耗时。权重缺失记“未测”，实测 OOM 记“该配置不可行”。两个状态分别保留。探测示范、参数更新和预测只存入 pilot 目录。

### 三条路线的时间外推

计时从模型装载、预热到稳态分开记录。每个能运行的配置用相同长度档重复计时，报告中位吞吐和观测范围。GPU 操作在计时边界同步。推理以完成的逻辑窗口/小时计，重试耗时计入有效吞吐。训练以完整优化器步/小时计，或按实际参与计算的 token 与对应 token/s 外推。

| 独立路线 | 串行墙钟估算 | 单卡 GPU 小时 |
|---|---|---|
| 主 pipeline | `M = L主 + 12,288/q四角色 + 2,048/q单评审 + A主` | 累计各段实际或预计占卡时长 |
| 主 pipeline + SFT | `M + L全参 + N教/q教 + H全参 + 12,288/q全参学生 + A学生` | 主线加教师生成、全参训练、学生重评等占卡段 |
| 主 pipeline + SFT + LoRA | `M + L适配 + N教/q教 + H适配 + 12,288/q适配学生 + A学生` | 主线加教师生成、LoRA 训练、学生重评等占卡段 |

- 所有时间统一换算为小时。`L` 为对应路线新增的加载、切换、预热、保存和重载开销，`A` 为 CPU 数据处理、聚合和评测时间，按实际阶段拆列。若 CPU 阶段仍持卡，计入占卡时长。共享的主线与教师生成在每条独立路线中各计一次。
- `N教` 是预计可构造的角色窗口数，上界为 `256×2×4=2,048`。用预计有效示范数（教师窗口数乘预计保留率）、有效 batch 和 1 轮训练推算优化器步数，再除以各训练方式的实测步/小时，得到 `H全参` 或 `H适配`。正式示范数尚未知时注明保留率假设，给出范围。学生重评均覆盖原 C 和 T 的四角色，复用原版 B1。
- 三条路线分别从同一原版主线出发。第三条的 SFT 通过 LoRA 实现，只计一轮适配器训练。全参数分支仅用于硬件与工时比较。若训练或重评未能实测，列出可估部分，依赖缺失的总时长填 NA 并说明原因。Phase 3 自身耗时单列。

**交接产物**为 `pilot/hardware.json`、原始计时及显存日志、`pilot/runtime_estimates.csv`。估算表每条路线列明工作量、配置、测量/假设来源、预计墙钟小时、GPU 小时与范围。测量完成后将三条路线回填[验收矩阵](./acceptance_result_matrix.md)。

## 3. 验收且可推进标准

- [x] 原版 8B、32B 教师、8B 全参数训练及 8B LoRA 训练各有配置、状态和证据。成功路径覆盖真实生成或优化器更新，失败路径保留可定位的错误。
- [x] 三条路线均有独立一行，能从窗口数、预计示范数、实测速率及固定开销复算，缺测项和替代速率明确标注。
- [x] 原版 8B 推理可用即可向[第 4 期](./phase4_agent_reviews.md)交接。教师或学生训练的局限记在各自扩展路径，时间估算用于排期。

2026-11-21 已通过本期验收。单卡主线、全参 SFT 路线、LoRA-SFT 路线预计分别为 **5.02、11.48、13.53 小时**。首批和补充示范的用途、参数更新证据、上限长度压力测试、实耗和估算范围详见[第 3 期验收记录](../../runtime/runs/v2-phase3-20261121/phase3_acceptance.md)。
