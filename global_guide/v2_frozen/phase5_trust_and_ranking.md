# 第 5 期｜校准、相关错误修正与双边重排

[主入口与公式](./experimental_setting.md) · 输入来自[第 4 期](./phase4_agent_reviews.md)的选票与第 2 期的 C 标签。向[第 6 期](./phase6_evaluation.md)交付冻结排名。本期使用 CPU。

## 1. 实验目标

只从 C 学习谁更可靠、哪些评审容易一起出错。在测试标签封存期间，为每位测试求职者生成全部方法的完整 10 岗排名。

## 2. 实验内容

1. C 内按人三折，对每个角色的 `pJ` 做温度校准。用样本外预测计算按人等权的 Brier 和 `rₐ=exp(−BSₐ/0.25)`。每对角色分别在 `J=0`、`J=1` 的对齐样本上计算残差相关，再对两类等权平均。保存六对相关、样本数和退化原因。测试使用完整 C 拟合的温度。
2. 以 D 校准 Preference 的 `pC`，仅以 C 中已投递岗位的 S 校准 Employer 的 `pE`。按照主入口 §3.2 处理单类样本、常量残差和缺失预测头。
3. 逐人生成 B1 和 B4，并在 B4 缓存上计算四个逐一移除角色的排名。T0 使用可靠度加权 PL，T1 采用主入口 §3.3 的正相关惩罚，两者 L2 系数均为 0.1。W1 复用 T1 的有效角色与归一化权重来求名次分平均。
4. 从 T1 名次得到 `R=(10−rank)/9`。按 `F=0.5R+0.5√(pC×pE)` 写出完整排序和前五。保留每个岗位的可信名次、两侧概率、最终分数和最终名次。B1 失效、多角色有效票少于两张或 PL 失败时依协议回退 BM25。可信排名可用且缺少双边预测时 F 回退 T1。

**交接产物**为 `base/calibration.json`、`base/oof.jsonl`、`base/rankings.jsonl` 及回退原因表。排名表用用户和方法标识关联同一初始名单。

## 3. 验收且可推进标准

- [ ] 每条样本外预测可追溯到剔除该用户的拟合折，温度、Brier、六对相关及两套权重可从 C 复算。参数来源中测试用户或测试标签的数量为零。
- [ ] 对同一查询验证 T1 与 W1 的有效角色和权重一致。核对 F 在 `R=1、pC=pE=1` 时得 1，并用缺头、少票和求解失败的样例验证协议回退。
- [ ] 六种主方法 B1/B4/T0/T1/W1/F 和四个角色移除对照均覆盖整份 T，包含回退用户。保存名单与排名哈希后，允许第 6 期评分程序读取 T 标签。

## 4. 补充实验结果｜跨 Agent 相关错误分析

正式校准参数和盲排结果封存后，用 C 的样本外共同头预测分析四个角色在哪些人岗对上容易出现相似偏差。六种角色配对均以同一求职者、同一岗位为观测单位。按第 2 节的定义，分别报告负例与正例的残差 Pearson 相关 `ρ₀`、`ρ₁`，以及两者的等权均值 `ρ`。每层列出配对求职者数、岗位数、相关的方向和退化原因。负例层关注高估程度是否同步，正例层关注低估程度是否同步。

用种子 `20261121` 在原三折内分别按求职者有放回重采样 2,000 次，每折保持原人数。每次抽中一人即同时带入其十岗、共同标签和四角色预测。每次在抽样后的两折重新拟合四个共同头的温度，在留出折生成样本外残差，汇合三折后计算六对系数。对三项统计量分别取第 2.5 和 97.5 百分位。分层样本不足或残差为常量时沿用第 2 节的替代值并记录退化次数。原数据上不可估的分层区间记为 NA。重采样拟合值用于区间估计，正式降权使用已封存的原始点估计。

在服务器本期运行目录交付六对角色的点估计与区间表、同色标的三幅并列相关热图，以及列出四角色 Brier、T0/T1 归一化权重和变化百分点的对照表。报告解释相关错误与权重变化。修正对测试排序效果的影响由第 6 期评价。核对报告点估计与正式校准产物一致，并复验补充分析前后的正式参数及排名哈希。
