# 第 8 期（Optional）｜学生 LoRA 训练与同榜配对评测

[主入口与冻结设置](./experimental_setting.md) · 输入为[第 7 期示范](./phase7_teacher_demos.md)及[第 6 期原版 F 结果](./phase6_evaluation.md)，完成后填写[结果矩阵的 Optional 栏](./acceptance_result_matrix.md)。

## 1. 实验目标

检验逐角色监督微调能否改善相同四角色 pipeline。配对比较只更换评审模型及由其预测重新估计的校准参数，数据名单、角色分工、窗口算法、聚合公式和评价口径沿用主线。

## 2. 实验内容

1. 从与主线相同 revision 的 Qwen3-8B 出发，用第 7 期示范训练**一个共享的角色条件 LoRA 适配器**。固定 `rank=16`、`alpha=32`、学习率 `10⁻⁴`、1 轮，按角色提示区分任务。保存训练所用示范哈希、目标模块、批量与梯度累积、精度、种子、实际训练步数和适配器校验值。
2. 使用学生在原 C 和 T 重做四角色滑窗。共 `(128+256)×32=12,288` 窗。B1 沿用原始缓存。将学生的选票、失败和回退写入单独目录。
3. 重做 C 内三折校准、Brier、六对相关和角色权重，重新校准 `pC` 以及已投递条件下的 `pE`。在同一 T 生成学生最终榜 F-SFT。原版和学生各自使用自己的权重，采用一致的 PL、双边公式和回退规则。
4. 固化学生排名后，沿第 6 期的同一分母计算五项指标，对联合 nDCG@5 做 F-SFT−F 的用户级配对差与 2,000 次 bootstrap 区间。将它记作解释性扩展比较。分别报告示范生成、学生训练、学生重评的 GPU 小时，再计算相对主线增加的总成本。

**交接产物**为 `distill/adapter/`、训练日志、`student/reviews.jsonl`、`student/calibration.json`、`student/rankings.jsonl`、`eval/student/`、更新的 GPU 账本与 Optional 结果栏。

## 3. 验收且可推进标准

- [ ] 单个适配器与所登记的 8B 快照可重新加载。示范、模型及运行版本可追溯，测试标签和原版测试指标均未用于训练或择模。
- [ ] 学生校准完全来自对应 C 的学生预测，C/T 用户、初始名单、评测分母与原版逐项相等。T 上每位用户都有最终榜或协议规定的回退榜。
- [ ] 矩阵列出 F-SFT−F、区间、有效配对人数、逐角色示范保留率、实际新增和累计 GPU 小时，以及证据路径。训练、重评与记账完整时将扩展标为“完成”。中断时登记实际阶段、已有产物和花费，完整配对结果保留至同榜评测完成后填写。
