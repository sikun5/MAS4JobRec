## 1. 填写规则与运行登记

### 1.1 状态约定

- **未开始**：尚未执行。
- **进行中**：已有运行，但尚未完成检查与结果冻结。
- **通过**：协议或产物满足验收条件，不用于表示假设已成立。
- **不通过**：已执行但不满足验收条件，必须说明原因。
- **阻塞**：缺少数据、端点、授权或预算等必要条件。
- **未运行（按计划裁剪）**：依据预算裁剪规则删除的次实验，必须写明触发原因。
- 数值格使用“待填”；不适用填 `NA（原因）`，禁止用 0 或破折号冒充缺失结果。

每个已填结果同时登记 `run_id`、样本数、split、标签来源、配置哈希与产物路径。不能将不同列表、不同标签来源、不同模型版本的结果拼成一个方法比较。
